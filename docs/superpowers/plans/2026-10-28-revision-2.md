# Revision 2 Implementation Plan

> Executed natively (superpowers:executing-plans), test-first. Spec: docs/superpowers/specs/2026-10-27-blind-sens-finder-design.md §16.

**Goal:** 3-part rounds (flicks, switching, tracking), 5 hidden steps, timer, breaks, game feel, play-area calibration.

## Global constraints
- Same constraints as the original plan: pure core, everything tunable in config, deterministic seeds, no test sens shown before results.
- Game-feel elements are display only and identical for every sens.

## Tasks
1. **Config and types:** add the switch block kind ('switch'), `SwitchBlockLog`, `Setup.padWidthCm: number | null`, `flick.blockMs` 20000 with `wavePerClass` 2, a `switch` config block, tracking 15 s with a 2 s lead-in, 5 dial-in steps, 3-way score weights, `pad.turnFraction`, and re-tuned diagnose refs. Validation accepts `padWidthCm`. Tests: config/setup.
2. **Switch content and runner:** `makeSwitchTargets(spec, cfg)` (a seeded list of aims in the forward region with a minimum separation), and `SwitchRunner` (3 active targets, hit → replace, time limit, log). Tests.
3. **Switch measurement and 3-way score:** `measureSwitch(log, cfg, rng)` → `SwitchSummary {tp, logTpSe, kills, accuracy, n}`, and `stepScore(flick, sw, tracking, baseline)`. Tests.
4. **Session:** steps are flick → switch → tracking; retry an invalid switch (n = 0); progress counts 3 blocks per step; `StepResult.switch`. Tests.
5. **Pad cap in steering:** the max test cm360 is min(limits.max·current, 2·turnFraction·padWidthCm). Tests.
6. **Simulator switching:** the sim player clears the nearest target with the flick motor model; `runSimSession` handles it. Tests. Then re-run the stats suite with 5 steps and calibrate per the original rules (never loosen thresholds).
7. **UI scoring:** `ScoreKeeper` (points, streak multiplier, tracking points per second) and `gradeFor(logS)`. Tests.
8. **Run controller:** chain the segments within a round, a break phase every `session.breakEveryRounds`, the `autoContinue` option, stage names in the HUD, and a segment timer from the runners' `endsAt`. Tests.
9. **Scene and sounds:** render switch targets, the pop effect, a brighter room; `sound.ts` with WebAudio synth. Build check.
10. **Run.tsx:** timer, live points and streak, break screen with stretch stats, sounds, the arrow to the nearest switch target. Browser check.
11. **Play-area calibration:** a calibration screen from Setup, `padWidthCm` saved, a setup warning, a results line. Tests for the pure conversion.
12. **End-screen stats and personal bests, README, final checks:** full test, stats and build, then one review.
